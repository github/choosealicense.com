Wenn du ein kreatives Werk erschaffst (und dazu gehört auch Code), bist du automatisch alleiniger Inhaber des Urheberrechts. Solange du keine Lizenz beilegst, die etwas anderes erlaubt, darf niemand sonst dein Werk kopieren, weitergeben oder verändern, ohne eine Abmahnung, eine Aufforderung zur Löschung oder eine Klage zu riskieren. Sobald weitere Leute am Werk mitgearbeitet haben (und damit jeweils eigene Urheberrechte daran halten), gehörst auch du zu diesem „niemand“.

Auch ohne Lizenzdatei räumst du unter Umständen einige Rechte ein, wenn du deinen Quellcode auf einer Plattform veröffentlichst, deren Nutzungsbedingungen du zustimmen musst. Wenn du deinen Code zum Beispiel in einem öffentlichen Repository auf GitHub veröffentlichst, hast du den [Nutzungsbedingungen](https://help.github.com/articles/github-terms-of-service) zugestimmt. Damit erlaubst du anderen, dein Repository anzusehen und zu forken. Manchmal brauchen andere deine Erlaubnis auch gar nicht, weil für ihren konkreten Fall [Schranken des Urheberrechts](https://de.wikipedia.org/wiki/Schranken_des_Urheberrechts) greifen. Weder die Nutzungsbedingungen einer Plattform noch die Schranken des Urheberrechts in einzelnen Ländern reichen aber für die Art von Zusammenarbeit aus, die man auf einer öffentlichen Code-Plattform normalerweise sucht: ausprobieren, verändern und teilen, so wie es eine Open-Source-Lizenz ermöglicht.

Um *keine* Lizenz anzubieten, musst du nichts tun. Es kann aber sinnvoll sein, an einer gut sichtbaren Stelle (z.&nbsp;B. in der README deines Projekts) einen Copyright-Hinweis und den Satz zu ergänzen, dass du keine Lizenz vergibst. So denken [Nutzer](#for-users) nicht, du hättest es einfach vergessen. Wenn du Beiträge anderer zu deinem Projekt ohne Lizenz annehmen willst, solltest du mit deinem Anwalt über eine Beitragsvereinbarung (Contributor Agreement) sprechen. Damit sicherst du dir die nötigen Rechte an den Beiträgen, auch wenn du selbst keine Rechte einräumst.

Vielleicht meinst du mit „keine Lizenz“ aber gar nicht, dass niemand deinen Code nutzen darf. Eine [Open-Source-Lizenz](/) erlaubt die Weiterverwendung deines Codes, während du das Urheberrecht behältst. Wenn du dich komplett von urheberrechtlichen Einschränkungen lösen willst, ist eine [Widmung als gemeinfreies Werk](/licenses/#unlicense) vermutlich das Richtige für dich.

## Für Nutzer
{: #for-users }

Wenn du Software ohne Lizenz findest, heißt das in der Regel, dass dir die Urheber nicht erlaubt haben, sie zu nutzen, zu verändern oder weiterzugeben. Auch wenn du den Code auf einer Plattform wie GitHub ansehen und forken kannst, bedeutet das nicht, dass du die Software für beliebige Zwecke nutzen, verändern oder weitergeben darfst.

Was du tun kannst:

{: .bullets}

- **Bitte die Maintainer freundlich, eine Lizenz hinzuzufügen.** Wenn nichts eindeutig dagegen spricht, wurde die Lizenz wahrscheinlich einfach vergessen. Liegt die Software auf einer Plattform wie GitHub, eröffne ein Issue, bitte darin um eine Lizenz und verlinke auf diese Seite. Wenn du dich traust und ziemlich klar ist, welche Lizenz am besten passt, kannst du auch direkt einen Pull Request mit einer Lizenz stellen. Schau dazu in der Seitenleiste jeder Lizenzseite unter „Diese Lizenz vorschlagen“ nach (z.&nbsp;B. bei [MIT](/licenses/mit/#suggest-this-license)).
- **Nutz die Software nicht.** Such dir eine Alternative unter einer Open-Source-Lizenz oder bau selbst eine.
- **Handle eine private Lizenz aus.** Bring am besten deinen Anwalt mit.
