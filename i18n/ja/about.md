GitHub は、開発者が自分のソースコードに合ったオープンソースライセンスを選ぶお手伝いをしたいと考えています。

すでに知識があり、使いたいライセンスが決まっているなら、それで構いません！考えを変えてもらうためにこのサイトがあるわけではありません。でも、選択肢の多さに戸惑っているなら、きっとお役に立てるはずです。

## すべてを網羅しているわけではありません

このサイトは、オープンソースライセンスを網羅したディレクトリではありません。大多数のプロジェクトにとっては、[ホームページ](/)で紹介している 3 つの選択肢のいずれかで十分でしょう。つまり、あなたのプロジェクトに似たプロジェクトで[好まれている](/community/)ライセンスを選ぶか、最も人気のあるパーミッシブライセンス（[MIT](/licenses/mit/)）か、最も人気のあるコピーレフトライセンス（[GNU GPLv3](/licenses/gpl-3.0/)）を選ぶことです。これらでは満たせない特別な要件がある場合に備えて、[検討に値するほかのライセンス](/licenses/)もいくつか紹介しているほか、[ソフトウェア以外のプロジェクト向けのライセンス](/non-software/)についてのページも用意しています。

[choosealicense.com リポジトリ](https://github.com/github/choosealicense.com)に収録されているすべてのライセンスの一覧表は[付録](/appendix/)をご覧ください。また、以下のリンクでは*さらに多くの*ライセンスを紹介していますが、プロジェクトに最適なライセンスを選ぶためにそれらを学ぶ必要は**ありません**。

## 改善にご協力ください

Choosealicense.com はオープンソースについてのサイトであるだけでなく、サイト自体もオープンソースです。もっと良くできると思うところはありませんか？ GitHub で気軽に[プロジェクトをフォーク](https://github.com/github/choosealicense.com)して、プルリクエストを送ってください。あなたの改善を歓迎します。
